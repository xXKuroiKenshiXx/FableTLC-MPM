# FableTLC-MPM v0.1.0-alpha

## Original baseline release

`v0.1.0-alpha` is the preserved initial build, before the newer work toward a host-authoritative multiplayer system. It is a technical foundation release, not a finished cooperative experience.

### What works

- Create or join a basic session.
- Spawn a remote player proxy in the other game instance.
- Synchronize basic position and rotation data.
- Configure connection settings and hotkeys through `egomp.ini`.

### What does not work yet

- Damage, health, attacks, death and combat authority.
- Enemy/NPC behavior and state.
- Inventory, spells, quests, doors, loot or persistent world state.
- Reliable map/region transition synchronization.

### Installation

Extract the package beside `Fable.exe`, edit `egomp.ini`, then start `EgoMP.exe`. The host opens a session; the client connects using the host address and port. Full instructions: [INSTALL.md](../../INSTALL.md).

### Before reporting a problem

Include your Fable executable version/hash, mod release tag, both players' network type (LAN/VPN/internet), the `egomp.ini` values with private addresses redacted, and the relevant log excerpt.
