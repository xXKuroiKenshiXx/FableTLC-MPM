# Changelog

## v0.1.0-alpha

Primera version publica preparada para repositorio/release.

### Incluido

- `EgoMP.exe` launcher del mod.
- `EgoMP.dll` modulo inyectado/cargado por el launcher.
- `egomp.ini` para configurar teclas, IP y puerto.
- Documentacion inicial de instalacion.
- Hashes SHA256 para verificar los archivos del paquete.

### Funciona actualmente

- Conexion basica host/cliente.
- Creacion de jugador remoto/proxy.
- Sincronizacion inicial de movimiento y rotacion.

### Pendiente

- Arquitectura host-authoritative real.
- Sincronizacion de vida y dano.
- Replicacion de enemigos/NPCs.
- Desactivacion o control de IA del cliente.
- Snapshots de mundo.
- IDs de entidades estables por region.
- Sincronizacion de animaciones, inventario, magia y estado de quests.

### Notas

Esta version es experimental y debe tratarse como base tecnica de investigacion.
